# Approved Tether logo

Status: approved by the user on November 19, 2026. The approved artwork is used
in `Frontend/tether/public/favicon.svg`. The preview files remain separate from
the application.

- `tether-mark-proposal.svg`: scalable source artwork with a transparent exterior.
- `tether-mark-preview.png`: browser-rendered preview of the SVG on the app's cream background.
- `preview.html`: standalone local preview; open directly in a browser.

The mark combines a capital T with a fountain pen nib to represent writing and
publishing. It uses the existing orange (`#E89951`) and dark ink (`#18190F`) colors.

The production favicon preserves the approved geometry and colors. Its versioned
URL in `Frontend/tether/index.html` refreshes previously cached browser icons.
